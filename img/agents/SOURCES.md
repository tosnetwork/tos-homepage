# Agent icon sources

All files in this directory are vendored copies of first-party product assets or official vendor-controlled brand assets. They are served locally by tos.network; no runtime hotlink is required.

- `openai.png` — OpenAI official GitHub organization avatar (used for Codex pending a distinct product-specific mark)
- `claude.png` — Anthropic Claude: `https://claude.ai/images/claude_app_icon.png`
- `cursor.svg` — Cursor official brand asset CDN
- `devin.png` — CognitionAI official `devin-extension` repository, `assets/devin-full-color.png`
- `gemini-cli.png` — Google Gemini CLI official repository
- `genspark.svg` — Genspark official CDN
- `github-copilot.svg` — GitHub official `CopilotForXcode` repository
- `hermes-agent.png` — Nous Research official `hermes-agent` repository
- `lobsterai.png` — NetEase Youdao official `LobsterAI` repository
- `manus.svg` — Manus official CDN
- `marvis.png` — Tencent-hosted Marvis asset
- `openclaw.svg` — OpenClaw official repository
- `pi.svg` — Pi official site icon: `https://pi.dev/favicon.svg`
- `windsurf.svg` — Windsurf/Exafunction official brand asset host
- `workbuddy.png` — Tencent-hosted WorkBuddy asset

Do not redraw, recolor, or substitute these marks with third-party logo-library versions.

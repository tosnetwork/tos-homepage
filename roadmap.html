Development priorities.

01

Post-quantum consensus

ML-DSA-44 consensus signing and verification, PQ validator descriptors, stable controllers, and protocol-18 canonical genesis. Public-network rollout requires verified configuration, operator key provisioning, and coordinated release procedures.

Implemented in source
02

Shielded native transfers

Contract, circuit, wallet, and ceremony tooling exist. Complete the production ceremony, independent verification, matching deployment identities, funding, and the frozen privacy profile’s acceptance gates before public activation.

Implemented · activation gated
03

Contracts and developer tools

Tol, FunC, Fift, sandbox execution, Agent Accounts, task escrow, multisig, and asset contracts form the development baseline. Continue improving tooling, integration coverage, client usability, and explicit failure handling.

Implemented · continued development
04

Validator and node operation

Full-node, validator, election, and health-monitoring tools are in the repository. Validate independent operators, recovery, monitoring coverage, release provenance, and sustained network behavior in the exact deployment domain.

Operational acceptance required

Follow the code and release evidence.

This roadmap describes the current source baseline, not live network telemetry or a promised launch date. Active protocol versions, validator sets, deployments, and performance must be verified against the selected network.

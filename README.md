# TOS Blockchain Homepage

Official static website for [TOS Blockchain](https://tos.network): **Blockchain for the Agentic Internet**.

The site focuses on the Layer-1 blockchain, post-quantum authentication, shielded TOS transfers, sharded TVM execution, smart contracts, developer tools, token configuration, and validator operation.

## Pages

- `index.html`: blockchain introduction
- `overview.html`: capabilities and AI-era application context
- `foundation.html`: technology and architecture
- `platform.html`: developer tools and contract primitives
- `privacy.html`: shielded transfer implementation and boundaries
- `pq.html`: post-quantum security
- `token.html`: native asset and issuance configuration
- `roadmap.html`: blockchain development and activation conditions
- `terms.html`: existing wallet terms

English HTML has matching Chinese, Japanese, and Korean translations in `js/i18n.js`. Shared layout is in `css/blockchain.css`; CSS and JS references use explicit cache versions.

Read [CONTENT_AUTHORITY.md](CONTENT_AUTHORITY.md) for technical claim boundaries and [CLAUDE.md](CLAUDE.md) for existing Cloudflare Pages deployment instructions.

Tools for native execution.

TOL

Express contract behavior

Typed contract storage, message receivers, and explicit state machines. Compiler checks cover state reachability, field scope, receiver coverage, and reply correlation. Some diagnostics are warnings, others errors.

FUNC · FIFT

Control cells and messages

FunC compiles contract logic to TVM instructions. Fift assembles code, constructs cells and initial states, and supports deployment workflows.

SANDBOX · EMULATOR

Test actual transactions

Exercise compute, action, and bounce behavior. The repository includes sandbox tests, circuit cross-checks, and negative controls for security-critical boundaries.

Contract primitives for autonomous applications.

ACCOUNT

Agent Account

Per-action and daily spending limits, owner policy, controller rotation, expiration, and replay protection.

SETTLEMENT

Task escrow

Creator-funded tasks with acceptance, result submission, review, disputes, and contract-defined settlement authority.

ASSETS

Tokens and markets

Jetton and NFT building blocks, highload wallets, multisig, and a binary prediction-market contract with collateral and resolution rules. Source availability is not deployment acceptance.

Start with a local chain.

Build the node and contract toolchain, create a disposable PQ network, and verify contract behavior before handling real funds. The local guide covers validator authorization, elections, and failure diagnosis. 

git clone https://github.com/tosnetwork/tos.git
cd tos
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --target validator-engine create-state gen_fif -j2
